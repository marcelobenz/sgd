# DOCNISYS - Sistema de Gestión Documental (SGD)

Sistema de gestión documental desarrollado en Laravel para la administración, control y versionado de documentos.

## 🚀 Funcionalidades principales

- Gestión de documentos con versionado
- Flujo de aprobación
- Control de permisos por usuario
- Recordatorios y notificaciones
- Dashboard con métricas
- Integración con almacenamiento en la nube (S3)

## 🛠 Tecnologías

- PHP / Laravel
- MySQL
- Bootstrap
- Vite / Node.js

## ⚙️ Instalación

```bash
composer install
cp .env.example .env
php artisan key:generate
npm install
npm run dev
